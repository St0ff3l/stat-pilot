# 深圳统计年鉴分析

## 来源选择

- 从客户端技能卡片启动时，客户端会先显示“官网检索”与“上传文件 / 粘贴链接”两个来源选项，并把选择写入任务提示。按该来源执行，不要再次询问来源，也不要用 `ask_user_question` 选择来源。
- 用户选择“官网检索”时，直接按下方官网流程查找年鉴并下载附件。
- 用户选择“上传文件 / 粘贴链接”时，优先处理已附加文件或已粘贴的链接；如果还没有文件或链接，提示用户拖入/选择文件或粘贴链接后继续，不要重新询问来源。
- 用户直接通过文字调用本技能、没有来源选择且没有附加文件或链接时，用普通对话简短说明两种来源供用户选择；不要调用 `ask_user_question`。
- 用户已经附文件或给出链接时，直接处理，不再询问来源。

## 官网检索与下载

1. 仅在官方政务域名中搜索：先搜深圳市统计局 `tjj.sz.gov.cn`，默认找最新的《深圳统计年鉴》；用户指定年份时按指定年份找。
2. 先读取[深圳市统计局统计年鉴目录](http://tjj.sz.gov.cn/zwgk/zfxxgkml/tjsj/tjnj/index.html)，确认条目标题和发布日期，再进入具体详情页。目录页不是年鉴正文。若统计局主站返回 403 或无法打开，改用[深圳政府在线的统计年鉴目录](http://www.sz.gov.cn/cn/xxgk/zfxxgj/tjsj/tjnj/index.html)及同一条目的详情页；该政府门户详情页标注“信息来源：深圳市统计局”，属于官方镜像。
3. 从详情页的“附件”链接取得 PDF 地址并跟进下载；不要根据旧年份 URL 猜附件地址，也不要只分析详情页的摘要。下载时 HTTP 优先，保存到工作区 `output/`，文件名使用安全的年鉴标题；下载后确认文件存在、大小非零且能识别为 PDF，再读取。若目录或详情页 HTTPS 访问异常，先尝试 HTTP；如果官方附件链接本身是 HTTPS，先尝试将其改为 HTTP。
4. 附件必须来自上述官方详情页，域名限于 `.gov.cn`。不得为了下载而关闭 TLS 校验、绕过安全策略或改用来历不明的镜像。
5. 官网页面或附件因网络、代理、证书、403 等问题无法读取时，明确说明卡在哪一步，保留官方详情页和附件地址，请用户下载后拖入客户端；不要声称已下载或已分析。

## 用户文件与链接

- 直接读取客户端已附加文件。对粘贴的 URL，先验证其指向官方详情页或附件；若详情页含附件，继续跟进附件，而不是把页面摘要当年鉴内容。
- 对文件直链或用户上传文件，记录原文件名、格式、页数/工作表；用户提供的来源在无法核实时标注“用户提供，来源待核验”。
- 如果给出的链接不是政务域名，遵守客户端网页白名单；不能抓取时让用户上传下载后的本地文件。

## 分析规则

- 年鉴版本年份、出版/发布日期和数据所属期分开记录。深圳统计年鉴 2025 可能主要呈现 2024 年数据，不能把版次直接当统计期。
- 先查目录和指标解释，再定位用户关心的表；保留表名、指标名、单位、统计期、地区范围、注释、数据来源和修订说明。PDF 引用同时注明书内印刷页码和 PDF 页序（两者不一致时都写）。Excel 引用注明工作表名和单元格/表格位置。
- 表格跨页、合并表头、脚注或 OCR 可能造成错读。对用于结论的关键数字回到原页/原单元格核对；提取不清时标为待核，不凭上下文补值。
- 优先用当前环境已有的 PDF 文本/表格提取工具；不要为本任务临时安装依赖。PDF 抽取结果不完整时，先检查该页是否是有意留白/章节扉页，还是表格以图片嵌入；不能因抽取文本为空就跳过。图片表应渲染后用可用的 OCR 或图像阅读能力读取，并逐格复核单位、行列和关键数字；若当前环境不能渲染/OCR，明确说明受限并请用户提供可读表格，不猜值。
- 跨年份比较前检查统计口径、行政区划、单位、价格基期和修订变化。口径不一致时分开展示或解释，不拼成连续序列。
- 结论区分描述、计算和因果判断。年鉴里的相关变化不能单独证明因果；派生值写明公式、输入值和舍入方式。
- 不复述整本年鉴。只提取回答问题所需表格与数据，并标注来源及具体页码/工作表，附官方详情页和可用附件链接。

## 默认输出

在对话中给出：

1. 年鉴版本、发布日期和数据覆盖期；
2. 结论摘要；
3. 指标表（指标、期间、地区、数值、单位、同比/变化、来源表名与页码/工作表）；
4. 口径说明、必要计算和限制；
5. 官方详情页及附件链接。

用户要求文件或报告时，再将精简结果写入工作区 `output/`；默认不生成冗长 HTML，也不把整本 PDF 复制进报告。

用户没有提出具体分析问题时，先按该版年鉴目录概述主要篇章和核心指标，标明数据覆盖期；不要为了“全书分析”机械抽取每张表。

## 2025 版已核对的 PDF 特例

《深圳统计年鉴2025》共 395 个 PDF 页，目录列出 19 个部分；正文主要反映 2024 年数据。正文页码与 PDF 页序不同，引用时保留两者。已确认 PDF 第 222 页（书内第 201 页，表 10-2）是图片表格，PDF 第 383 页（书内第 362 页，表 18-3）的数据区也是图片；常规文本/表格提取会漏掉这些数值，需渲染后 OCR 或视觉核验。章节扉页和留白页也可能没有可提取文本。其他版次需重新检查，不可沿用这些页码假设。
